# 前端模块

前端按业务功能组织，便于成员直接负责一个目录：

```text
src/
├── app/                 应用入口、角色导航和模块组装
├── features/
│   ├── auth/            登录、会话和用户身份
│   ├── catalog/         食堂、楼层和窗口目录
│   ├── management/      管理部门工作台
│   └── admin/           平台管理
└── shared/              两个以上模块复用的无业务代码
```

依赖方向固定为 `app → features → shared`。功能模块不引用 `app`，也不直接引用其他功能模块；跨模块页面由 `app` 组装。新代码先放进所属功能目录，出现第二个真实使用者后再移动到 `shared`。

`catalog` 只负责食堂、楼层和窗口目录；开始评价、讨论和有帮助功能时，新建 `features/community`，不要把社区代码放进目录模块。
